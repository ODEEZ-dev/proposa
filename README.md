# Proposa

AI-powered proposal generator for freelancers. Write, send, and track client proposals — with AI doing the heavy lifting.

## What it does

Proposa takes your project details, matches them against your service catalog, and generates a full proposal in under 30 seconds. Clients get a clean, branded page to accept or request changes. You get a dashboard that tracks everything.

## Features

### Proposal Generation
- **AI-powered creation** — Fill out a 4-step intake wizard (client, project details, scope & budget, review) and get a complete proposal generated by AI
- **Rich text editor** — WYSIWYG editor with formatting toolbar (headings, lists, links, quotes) and auto-save
- **AI assistant** — Chat with AI to refine tone, add payment terms, reduce scope, or rewrite sections — one click to apply changes
- **Smart service matching** — AI picks the right services from your catalog based on project scope

### Client-Facing Proposal Page
- **Branded share links** — Each proposal gets a unique URL with your logo, business name, and primary color
- **Accept or request changes** — Clients can accept (with confetti celebration) or leave feedback directly on the page
- **Live view tracking** — Know when a client opens your proposal and see a "client is viewing" indicator in real time

### Client Management
- **Client profiles** — Track name, email, company, industry, and notes for each client
- **Client stats** — Auto-calculated win rate, total value, and proposal count per client
- **Proposal history** — Full filtered view of all proposals for any client

### Services Catalog
- **Service definitions** — Name, description, category, pricing, duration, and deliverables
- **Active/inactive toggle** — Hide services you're not currently offering
- **Category grouping** — Services organized by web development, design, marketing, consulting, content, other

### Dashboard
- **Key metrics** — Proposals this month, win rate, hours saved, revenue from accepted proposals
- **6-month trend chart** — Visual bar chart of proposal volume over time
- **Recent activity feed** — Timeline of proposal created/sent/accepted, client added, intake completed
- **Quick actions** — Floating button for one-tap access to create proposal, add client, add service

### Settings
- **Brand customization** — Business name, tagline, primary color, logo upload — with live preview of how proposals will look
- **Proposal defaults** — Default terms & conditions, payment terms, proposal expiry, tone
- **Account management** — Edit name, request account deletion

### General
- **Responsive design** — Full sidebar on desktop, slide-out drawer on mobile
- **Dark workspace** — Dark app surfaces with light paper for client-facing proposals
- **Onboarding wizard** — 3-step setup for new users (business name, services, logo)
- **Toast notifications** — Success/error feedback on all actions
- **Bulk operations** — Select multiple proposals to change status or delete

## Getting Started

### Prerequisites
- Node.js 18+
- A [Convex](https://convex.dev) account (free tier works)
- An [OpenAI](https://platform.openai.com) API key

### Setup

```bash
# Clone the repo
git clone https://github.com/ODEEZ-dev/proposa.git
cd proposa

# Install dependencies
npm install

# Set up Convex
npx convex dev
# (Follow the prompts to create a project)

# Create your env file
cp .env.local.example .env.local
# Add your Convex URL and OpenAI key

# Start the dev server
npm run dev
```

Open [http://localhost:5174](http://localhost:5174) to see the app.
